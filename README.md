 Cost Tracker Sidebar

A Google Apps Script-based cost tracking sidebar designed to make expense entry and management simple and efficient.

About the Project

Cost Tracker sidebar provides a sidebar interface connected to Google Sheets. It allows users to enter and manage cost-related information without having to work directly inside the spreadsheet.

Features

- Add cost/expense entries
- User-friendly sidebar interface
- Google Sheets integration
- Easy to manage and update

Technologies Used

- Google Apps Script
- HTML
- CSS
- JavaScript
- Google Sheets

Setup

Open a Google Sheet.
Go to Extensions → Apps Script.
Add the contents of Code.gs.
Add Sidebar.html as an HTML file.
Save the project.
Run the required function from Apps Script.
Open the sidebar and start adding cost entries
